# راهنمای ادمین‌های مستقل وب Nexora

## چرا لازم است؟
اگر همه از رمز مشترک `ADMIN_WEB_PASSWORD` استفاده کنند، هویت فردی قابل تشخیص نیست. برای ثبت عملیات به شناسهٔ واقعی هر ادمین، از متغیر Worker به نام `ADMIN_WEB_USERS` استفاده کن.

## پیکربندی امن
مقدار این Secret باید آرایهٔ JSON باشد. هر حساب شامل نام کاربری، رمز قوی و Telegram ID عددی متعلق به همان ادمین است:

```json
[
  {
    "username": "admin-one",
    "password": "USE_A_UNIQUE_RANDOM_PASSWORD_AT_LEAST_12_CHARS",
    "telegram_id": 123456789
  },
  {
    "username": "admin-two",
    "password": "USE_ANOTHER_UNIQUE_RANDOM_PASSWORD",
    "telegram_id": 987654321
  }
]
```

شناسه‌ها را با Telegram ID واقعی ادمین‌ها جایگزین کن و رمزهای نمونه را استفاده نکن. این JSON را داخل مخزن یا فایل عمومی قرار نده.

از ریشهٔ پروژه Secret را تنظیم کن:
```bash
npx wrangler secret put ADMIN_WEB_USERS
```
سپس JSON را در ورودی مخفی ترمینال قرار بده. `ADMIN_SESSION_SECRET` نیز باید از قبل با یک مقدار تصادفی و قوی تنظیم شده باشد.

وقتی `ADMIN_WEB_USERS` معتبر و دارای حساب باشد، ورود با نام کاربری و رمز همان حساب انجام می‌شود و شناسه از نشست احراز‌شده گرفته می‌شود؛ هیچ فرم وبی نمی‌تواند شناسهٔ ادمین را خودش تعیین کند. در این حالت رمز مشترک قدیمی برای ورود استفاده نمی‌شود. اگر `ADMIN_WEB_USERS` تنظیم نشده باشد، ورود قدیمی با `ADMIN_WEB_PASSWORD` همچنان کار می‌کند، اما عملیات آن ورود مشترک در گزارش با شناسهٔ صفر ثبت می‌شود و هویت فردی تضمین نمی‌شود.

## Migration و انتشار
این نسخه migration جدید `0011_web_admin_workflows.sql` دارد که ستون‌های هویت نشست و پیش‌نویس Broadcast را اضافه می‌کند. قبل از انتشار کد جدید روی Worker زنده، migrationهای D1 را روی دیتابیس Remote اعمال کن. دستور پروژه هر دو کار را به ترتیب انجام می‌دهد:

```bash
npm run deploy:cloudflare
```

پس از انتشار:
1. با هر حساب مستقل جداگانه وارد شو.
2. در «امنیت و گزارش‌ها» بررسی کن که نشست‌ها نام کاربری و Telegram ID درست را نشان می‌دهند.
3. در «پیام‌رسانی» پیش‌نویس بساز، «ذخیره و پیش‌نمایش» را بزن و فقط پس از بازبینی نسخهٔ پیش‌نمایش‌شده، ارسال را تأیید کن.
4. با هر ادمین یک عملیات بی‌خطر انجام بده و گزارش را برای تأیید شناسه بررسی کن.
